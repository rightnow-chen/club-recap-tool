## 异常案例

| 异常 | 处理方式 | 输入是否保留 |
| --- | --- | --- |
| 网络失败 | 返回“无法连接模型服务，请检查网络后重试。” | 是，客户端 generation_history.input 不清空 |
| 模型超时 | `AbortSignal.timeout` 后返回“模型请求超时，请稍后重试。” | 是 |
| 非法 JSON | 解析层返回“模型没有返回合法 JSON，请重试。” | 是 |
| 空输出 | 返回“模型响应为空，请重试。” | 是 |
| 必填字段缺失 | 400 字段级错误，不调用模型 | 是 |

执行：

```bash
npm run check
npm run test:phase5
PHASE5_RUN_LLM=1 npm run test:phase5
```

`PHASE5_RUN_LLM=1` 会真实调用模型，耗时取决于模型服务；普通契约测试默认不调用模型。
